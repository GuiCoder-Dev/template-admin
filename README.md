# Template Admin

Template de painel administrativo desenvolvido com **Next.js**, **React**, **Tailwind CSS** e **Firebase Authentication**.

## 🎯 Sobre o projeto

O projeto consiste em um template de painel administrativo com sistema de autenticação de usuários.

A aplicação permite realizar cadastro e login utilizando **e-mail e senha** ou **Google**, além de possuir controle de sessão, logout e proteção de páginas que necessitam de autenticação.

## 🚀 Tecnologias

- NextJS
- ReactJS
- TypeScript
- Tailwind CSS
- Firebase 

## ▶️ Como executar

Clone o repositório:

    git clone git@github.com:GuiCoder-Dev/template-admin.git

Entre na pasta:

    cd admin-template

Instale as dependências:

    npm install

Configure as variáveis do Firebase no arquivo `.env.local`.

Execute o projeto:

    npm run dev

Acesse no navegador:

    http://localhost:3000

## 📚 Objetivo

Projeto desenvolvido com o objetivo de praticar conceitos de **React e Next.js**, como componentes, Context API, hooks, autenticação, gerenciamento de estado e proteção de páginas.

Também foi utilizado o **Firebase Authentication** para implementar o sistema de autenticação da aplicação.
